# Câmbio Claro 1.7.8 — linha intradiária contínua

- Mantém um único gráfico de linha intradiária, com segmentos verdes para altas, vermelhos para quedas e cinza para estabilidade.
- Conecta cada publicação real à seguinte com linha sólida mesmo quando há intervalo sem atualização.
- A conexão entre dois pontos é só uma ligação visual das observações existentes; o app não cria, armazena ou apresenta cotações intermediárias.
- O trecho após o último ponto mostra o último preço retido até nova publicação e permanece separado no status da cotação.
- Toque/arraste seleciona um ponto e mostra horário, preço e variação absoluta/percentual. A lista mantém cada publicação real em detalhe.
- `versionCode=21`, `versionName=1.7.8`.
